# Customer Behavior & Sales Insights Dashboard (Excel)

## Overview
Interactive Excel dashboard analyzing customer behavior and sales performance.

## Features
- KPI tracking (Orders, Revenue, Quantity, Rating, Delivery Time)
- Weekly and monthly trends
- Customer purchase analysis
- Product performance insights

## Tools Used
- Microsoft Excel
- Pivot Tables & Charts
- Slicers
